# Static Repo Index

> Parent: [Brain Versioning](brain-versioning.md)

The Static Repo Index is the committed, agent-readable layer of the Repo Brain — a set of markdown files written to `.repo/` that allow any LLM agent on any branch to navigate brain state without requiring the running Postgres infrastructure. These files are called 'brain-crumbs': thin pointer files that surface topics, insights, and file relationships in a format optimized for agent consumption, not human documentation. The index is generated by `src/brain/generate-markdown.ts` from the brain's Postgres tables after each brain run, then committed to the repo as part of the brain versioning lifecycle. Critically, the index is evidence-scoped — it only includes files that have actually been touched by sessions or commits, organized into semantic groupings (what files do together) rather than by directory path or exhaustive repo enumeration. The knowledge graph it exposes is bidirectional: a topic file lists all related source files, and the top-level entry point allows navigation from file back to topics, enabling UI and agent workflows like 'show me all topics this file participates in' or 'show me all files relevant to this topic'.

## structure

- The knowledge graph exposed by the static index is bidirectional: topic files list all related source files, and the top-level brain entry point supports reverse navigation from file to topics. This enables both 'what files relate to this topic?' and 'what topics does this file participate in?' queries.

## constraint

- The static index is NOT a full repo map. It only indexes files touched by sessions or commits (evidence-scoped), and organizes them by semantic groupings — what files do together — not by directory path or individual file listing.

## decision

- The `.repo/` markdown files are 'brain-crumbs' — agent-facing navigation artifacts committed to the repo so any agent can read brain state without infrastructure, not human-facing documentation or dashboards.

## behavior

- After each brain run, `generate-markdown.ts` reads from the brain Postgres tables and writes the `.repo/` markdown files using relative file paths and deduplicating evidence per topic before committing them as part of the brain version snapshot.

## interface

- `.repo/brain.md` is the canonical agent entry point into the static index — the top-level brain-crumb that agents should read first to orient themselves before navigating to topic-specific files under `.repo/topics/`.
