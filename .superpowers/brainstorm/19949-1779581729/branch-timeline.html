Brain versions are tags on commits. Where does this timeline live?

A

Overview Page — Timeline Section

The Overview landing page (no topic selected) shows a git-log-style vertical timeline as its main content. Each commit is a row, brain versions appear as 🧠 tags with a summary of what changed. Clicking a brain version tag could filter topics to show what was added/changed in that version.

Left Sidebar — Below Topics

The sidebar has two sections: "Topics" (list) and "Timeline" (compact commit list with brain tags). Always visible, compact. Clicking a brain version filters the topic list to show what changed.

C

Separate "Timeline" View — Sidebar Nav Item

Add a third nav item in the sidebar: Topics | Timeline. Timeline replaces the center content with the full branch view. No split — just the timeline taking the full center. Clicking a brain version drills into what changed.
