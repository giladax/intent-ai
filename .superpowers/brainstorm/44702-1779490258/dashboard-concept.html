Dashboard Concept — Spatial Session Explorer

Not a list of sessions — a living map of how your project's understanding evolved

A

Constellation View

Sessions are stars in a 2D space. Proximity = semantic similarity (embeddings projected via UMAP/t-SNE). Clusters form naturally — "the auth arc", "the performance sprint". Type a question in a search bar and the map recolors: sessions relevant to your query glow, irrelevant ones fade. Click a cluster to zoom in, click a session to open it.

B

Search-First with Dynamic Grouping

Big search bar dominates. Type anything — sessions regroup dynamically by relevance. Empty state shows sessions grouped by auto-detected clusters (time, topic, arc). The grouping IS the KNN — similar sessions cluster together. Click a group to expand, click a session to open with chat.

C

Hybrid — Constellation + Search Recoloring + Chat Panel

Constellation as the default view (spatial overview). Search bar recolors the map AND reranks a sidebar list. Chat panel on the right answers questions using relevant sessions as context. Project selector in the header. Best of both worlds.

Layout: Header (project selector) → Main area (constellation map) → Right panel (chat) → Search bar (overlaid on map, recolors dots + shows ranked list below)
