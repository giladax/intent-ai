Dashboard UX Direction

How should the center content area work when a user drills into a topic?

A

Narrative-First → Chat Continues

Center shows the narrative as a readable document. A "Chat" tab or toggle switches to a conversation view where the narrative is the first assistant message, and the user continues asking questions. Sessions appear as context chips above the chat input.

Flow:
Topics list → Click topic → See narrative text → Toggle to "Chat" → Narrative becomes first message → Ask follow-up questions
B

Chat-First with Narrative as Context

Center IS a chat from the start. When you select a topic, the narrative appears as the first assistant message automatically. No tab switching — you're already in the conversation. Session details are expandable cards within the chat flow.

Flow:
Topics list → Click topic → Chat opens with narrative as first message → Start asking questions immediately
C

Split View — Narrative + Chat Side by Side

Center splits into two panels: left shows the narrative/insights as a document, right is a chat panel scoped to that context. No switching, both always visible. Clicking a session in the narrative scrolls the document.

Flow:
Topics list → Click topic → See narrative (left) + chat (right) simultaneously → Reference narrative while chatting
