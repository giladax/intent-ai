# Quire — Pitch Kit (2026-07-20)

Prepared by outside pitch counsel. Founder brief only; no code, no internal docs. Everything here is sayable in a room.

---

## 1. The Elevator

**15 seconds:**
> "AI writes most code now, so teams ship faster than they understand. Quire reads what a company promised to build, watches every merge, and flags the moment the code breaks a promise — with the exact file and line. Every AI coding tool makes this problem worse. We're the check on all of them."

**60 seconds:**
> "Every software company makes promises — to customers, to regulators, to itself. 'Refunds over $10K always get human review.' Those promises live in documents nobody re-reads. The code drifts away from them silently, and you find out in an incident.
>
> That was survivable when humans wrote the code slowly. It isn't anymore: AI now writes most of the code, merges land hourly, and no human holds the whole picture. The gap between what a company *said* and what it *shipped* is now the biggest unpriced risk in software.
>
> Quire closes that gap. It reads the specs, watches every merge, and keeps a living map of every promise and whether the code still keeps it. When something drifts, it tells you — with the file and line as evidence. It can't assert anything it can't cite, and humans sign off on everything, so the record is trustworthy enough to run a company on.
>
> It already caught real drift in our own repo. Onboarding a new repo takes an afternoon and about a dollar. The AI-codegen wave is the tailwind: the more code AI writes, the more every team needs an independent witness. That's Quire."

## 2. Positioning

**Category name: Intent Assurance.** (Say it, then explain it in one breath: "AI code review checks if code is *good*. We check if it's still *what you meant*.") It borrows the credibility of "quality assurance" and the budget-line familiarity of "assurance," and it's whitespace: AI code review is a ~$420M-ARR knife-fight at the pull request ([CodeRabbit at ~$550M valuation](https://siliconangle.com/2025/09/23/greptile-bags-25m-funding-take-coderabbit-graphite-ai-code-validation/), [Greptile at $180M](https://sacra.com/c/coderabbit/)); spec-driven dev tools (Tessl, Kiro, GitHub Spec Kit) all work *before* the code is written ([the category is real and named](https://thebcms.com/blog/spec-driven-development)). Nobody owns *after the merge, forever*.

**For / against / unlike:**
- **For** engineering and product leaders at AI-heavy teams (50–500 engineers)
- **who** can no longer say with confidence that the product still does what they promised,
- **Quire** is an intent-assurance layer that continuously verifies shipped code against stated intent,
- **unlike** AI code reviewers (which judge one PR's quality, then forget) and spec-first tools (which help you write intent but never check it again),
- **it** maintains a living, cited, human-signed record of every promise and its status — and cost scales with change rate, not repo size.

**The wedge: drift-catching. Full stop.** Not org memory (Glean's shadow, vague ROI, long sale). Not AI governance (real budget but a 2027 committee sale). Drift-catching is demoable in 90 seconds, lands as fear ("this is silently happening to you right now"), has an incident-shaped ROI story a CFO understands, and the other two markets are what you *grow into* once the map exists. Lead with the alarm; the memory is the moat.

## 3. The Deck — 10 slides, one line each

1. **Problem** — AI writes the code now; teams merge faster than anyone understands, and what a company *promised* drifts from what it *shipped* — silently, until an incident.
2. **Insight** — Intent and implementation are two data streams about the same thing; nobody diffs them continuously, because until now nothing could read both.
3. **Product** — Quire reads your specs, watches every merge, and maintains a living map of every promise and whether the code still keeps it — with file-and-line evidence for every claim.
4. **Demo moment** — [Live] A merge lands; Quire flags "the promise 'high-risk refunds are never auto-approved' broke at `refunds.ts:142`" — and the plain-English narrative updates itself, every sentence machine-verified.
5. **Proof** — It caught real drift in its own repo (file and line on screen); a cold external repo onboarded in one afternoon for ~$1; a 6k-commit OSS repo scale run in flight; browsing the map costs zero model calls.
6. **Moat** — A verified, org-specific system of record: the AI can only state what it can cite (auditable, not vibes), every conclusion is signed by a named human (the record becomes load-bearing), and it learns each org's own vocabulary — so the data asset compounds with every merge and is worthless to a competitor who shows up later.
7. **Market** — Every AI-codegen dollar creates unverified change; AI code review hit ~$420M ARR in 3 years on "is this PR okay?" — "is the product still what we promised?" is the bigger question, asked by more senior buyers.
8. **Business model** — Per-repo SaaS priced on change volume (our costs literally scale with change rate, not repo size — margin is structural); land on one critical repo, expand to the org.
9. **Team + ask** — [Founder line: the person who built the pipeline that can't lie]; hiring one founding engineer and one design partner lead.
10. **The round** — Raising [$X] pre-seed plus compute credits to convert 5 design partners and publish the 6k-commit public scale run as the category's proof point.

## 4. Language Rules

**Five phrases to USE in the room:**
1. "**Teams merge faster than they understand.**" (the problem, eight words)
2. "**It can't say anything it can't cite.**" (trust, in plain English)
3. "**File and line, or it doesn't get said.**" (evidence standard — repeat it)
4. "**Cost scales with change, not repo size.**" (the margin sentence VCs remember)
5. "**Every AI coding tool makes our problem bigger.**" (the tailwind, weaponized)

**Ban list — internal words that die at the door:**

| Banned | Say instead | Why |
|---|---|---|
| **quires** | (nothing — company name only) | A unit called a "quire" needs a paragraph of explanation. You have 15 seconds. |
| **the mind** | "the living map" | "The mind" sounds like AGI theater; investors flinch. |
| **signing** | "human sign-off" / "a named human approves it" | "Signing" reads as crypto or DocuSign. Sign-off is universal. |
| **colophon** | (kill entirely) | Nobody in the room knows the word; the ones who do will think you're precious. |
| **entities** | "promises and the parts of the product" | Database word. Zero emotional content. |
| **verdicts** | "kept / broken" (a promise is kept or broken) | Courtroom-cosplay; "broken promise" is stronger and human. |
| **drift** (bare) | "spec-drift" or "the code drifted from the promise" | Keep it — but always anchored to *from what*. |

**Survivors:** "promises" (your best word — use it relentlessly), "the map," "checks," anchored "drift."

## 5. Objection Scripts

**"Cute demo. Toys demo well."**
> "Fair — so we didn't demo a toy. That drift on screen is from our own production repo; we onboarded a repo we'd never seen in one afternoon for about a dollar, and we're running it over a 6,000-commit open-source codebase right now — that run will be public. The unit economics are the tell it's not a toy: analysis only runs when code changes, so a huge dormant repo costs almost nothing. Toys don't have a cost curve."

**"GPT-next eats you."**
> "GPT-next makes our input better and our moat deeper — we're a consumer of frontier models, not a competitor to them. What the model can never generate is our data: three years of an org's promises, human sign-offs by name, and its own vocabulary, accumulated merge by merge. A better model dropped into Quire makes Quire better. A better model without that record is a smarter amnesiac. And structurally: the more code models write, the more someone independent has to check it against intent. We're short human code-writing and long model quality."

**"Who buys this? Who's the champion?"**
> "The VP Engineering at an AI-heavy company, and the trigger is an incident — the moment someone asks 'wait, when did we stop doing human review on big refunds?' and nobody can answer. That person has budget, has just felt public pain, and can adopt us on one repo in an afternoon without a platform decision. The CPO and compliance become the expand motion, because we're the only place where 'what did we promise?' has a cited answer. Land: one burned VP Eng, one critical repo. Expand: every repo that carries a promise."

**"Isn't this Glean? Sourcegraph?"**
> "They answer 'where is X?' We answer 'is X still true?' Glean searches what people wrote; Sourcegraph searches what people coded; neither ever says 'these two disagree, here's the line, a human confirmed it.' Search retrieves; assurance *verifies* — different verb, different buyer, different willingness to pay. If anything, they validated that org knowledge is a real budget line; we're the layer above it that turns knowledge into a checked commitment. And our record — cited, signed, org-specific — is exactly the data they can't backfill."

## 6. The 90-Second Laptop Demo

Two moments, in this order — the alarm, then the trust:

**Moment 1 — The catch (~50s).** Open the map on a real repo. Show one promise in plain English ("high-risk refunds are never auto-approved") with status **broken** — click it, land on the exact file and line, next to the spec sentence it violates. Say: "Nobody told it to look here. It noticed." This is the whole company in one click.

**Moment 2 — The witness (~40s).** Show the running narrative: "This promise broke Tuesday at `refunds.ts:142`; fixed Thursday in #482 — approved by Dana." Click any sentence → it resolves to the underlying evidence and the named human sign-off. Say: "Every sentence is machine-checked against the record. It cannot say anything it can't cite." Close the laptop.

Do NOT show: onboarding, settings, search, the pipeline, or anything with a spinner. The $1/afternoon onboarding is a *sentence*, not a screen.
